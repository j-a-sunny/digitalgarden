# Jasper's Digital Garden

Welcome! This is my personal [Obsidian](https://obsidian.md) vault, published as a digital garden. It's where I keep study notes, Linux and NixOS tinkering, ideas, and writing. Nothing here is finished; notes grow and change over time.

🌐 **Live site:** [jaspersdigitalgarden.netlify.app](https://jaspersdigitalgarden.netlify.app/)

## What's inside

| Section | What you'll find |
| :-- | :-- |
| **Study** | Semester notes and worked solutions (BBA coursework, mathematics question banks, reports) |
| **Linux** | Setup notes, configs, and things I've figured out the hard way |
| **Production** | Work-in-progress projects and build notes |
| **Word-Smith** | Writing and wording experiments |
| **Ideas** | A running list of things I want to try |
| **Resume** | My [[RESUME\|resume]] |

## How it's built

- Notes are written in Obsidian using Markdown, with LaTeX for maths.
- Published with the [Digital Garden plugin](https://github.com/oleeskild/obsidian-digital-garden) and hosted on Netlify.

## A note on the notes

Study notes may contain mistakes, so double-check anything important before relying on it.
